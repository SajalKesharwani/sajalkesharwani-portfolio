# Sajal Kesharwani — Personal Portfolio Website

A minimal, high-contrast monochrome single-page portfolio for **Sajal Kesharwani** (Software Engineer & Full-Stack Developer).

- **WorkBridge**: [https://workbrdge.netlify.app/](https://workbrdge.netlify.app/)
- **LRNit**: [https://lrnitclub.netlify.app/](https://lrnitclub.netlify.app/)

## 🛠️ Tech Stack & Design System
- **Core**: React 18, HTML5, Vanilla JavaScript & Modern CSS
- **Styling**: Tailwind CSS CDN + Custom Monochrome Stylesheet (`#0A0A0A`, `#141414`, `#262626`, `#F5F5F5`, `#FFFFFF`)
- **Typography**: Space Grotesk (Headings), Inter (Body), JetBrains Mono (Badges/Dates/Code)
- **Icons**: Lucide Icons
- **Key Features**:
  - Smooth anchor-link scrolling & active scroll-spy navigation (`#about`, `#skills`, `#projects`, `#achievements`, `#education`, `#contact`)
  - Dynamic typewriter terminal effect in Hero section
  - High-impact project showcase cards with technical architecture details and live links
  - One-click copy email / phone with animated toast notifications
  - 100% responsive across mobile, tablet, and desktop screens

## 🚀 How to Run Locally

You can serve the project using Python's built-in HTTP server:

```bash
# In the project directory
python -m http.server 3000
```

Then open `http://localhost:3000` in your web browser.
